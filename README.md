# Developer Portfolio

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

A fast, responsive, and modern developer portfolio built with React 19, Vite, Tailwind CSS 4, Framer Motion, and AOS.

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```

### 2. Lint the Code
```bash
npm run lint
```

### 3. Build for Production
```bash
npm run build
```
